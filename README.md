# Kipos Garden Design

Je veux créer un site vitrine professionnel pour une entreprise de conception paysagère appelée **Atelier Kipos**.

IMPORTANT :

* Le site doit être construit comme un véritable site professionnel prêt à être mis en ligne.
* Je veux reproduire fidèlement le design, la structure, l'ambiance et les fonctionnalités décrites ci-dessous.
* Ne crée pas un design générique de site paysagiste.
* Respecte précisément les couleurs, typographies, espacements, proportions, animations et contenus indiqués.
* Le résultat doit être élégant, haut de gamme, végétal, méditerranéen, contemporain et minimaliste.
* Le site doit être parfaitement responsive sur ordinateur, tablette et mobile.
* Le code doit rester propre, organisé et facilement modifiable.
* Évite les fonctionnalités inutiles ou complexes.
* Je veux pouvoir héberger ensuite le site indépendamment de cette plateforme.
